# 🔧 تعمیرامیر — toostamir.ir

سایت فروشگاهی/خدماتی تعمیرات لپ‌تاپ و موبایل با **پنل مدیریت محصولات** و **فرم تماس**.

## اجرای پروژه
```bash
cd toostamir
npm install
npm start          # http://localhost:3000
```

## صفحات سایت
| مسیر | توضیح |
|---|---|
| `/` | صفحه اصلی (اسلاید placeholder، محصولات، اعتمادسازی) |
| `/products` | لیست محصولات + جستجو و فیلتر دسته |
| `/product/:id` | جزئیات محصول (قیمت استعلامی برای خدمات) |
| `/services` | خدمات تعمیرات (با گارانتی تعمیرات) |
| `/warranty` | شرایط گارانتی تعمیرات |
| `/contact` | فرم تماس / استعلام (پیام‌ها در پنل مدیریت ذخیره می‌شوند) |

## پنل مدیریت
| مسیر | توضیح |
|---|---|
| `/admin/login` | ورود مدیر — کاربری: `admin` رمز: `admin123` (از بخش تنظیمات تغییر دهید) |
| `/admin` | داشبورد (آمار محصولات و پیام‌ها) |
| `/admin/products` | لیست محصولات: ویرایش / حذف / فعال-غیرفعال |
| `/admin/products/new` | ➕ افزودن محصول (نام، دسته، قیمت تومان، قیمت قبل از تخفیف، موجودی، تصویر، توضیحات) |
| `/admin/messages` | پیام‌های فرم تماس (خوانده‌شده / حذف) |
| `/admin/settings` | تغییر رمز عبور مدیر |

## تصاویر Placeholder
تا زمان آماده شدن تصاویر واقعی، همه تصاویر بصورت **Placeholder** نمایش داده می‌شوند.
برای هر محصول در پنل مدیریت می‌توانید آدرس تصویر وارد کنید (مثلاً `/public/img/laptop1.jpg`)؛ فایل‌ها را در پوشه `toostamir/public/img/` قرار دهید.

## وضعیت پرداخت (زرین‌پال)
⚠️ اتصال به درگاه **زرین‌پال** هنوز انجام نشده و در حال انجام است. تا آن زمان:
- استعلام قیمت و سفارش بصورت **تلفنی** یا از طریق **فرم تماس** انجام می‌شود.
- پیام‌های فرم تماس در پنل مدیریت → «پیام‌های تماس» قابل مشاهده هستند.
